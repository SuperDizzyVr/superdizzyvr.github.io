# SuperDizzy VR website

Public GitHub Pages website for SuperDizzy VR.

- English privacy policy: https://superdizzyvr.github.io/privacypolicy/
- German privacy policy: https://superdizzyvr.github.io/datenschutz/

The former `/` and `/de/` pages redirect to the respective policies. The new
paths also work without a trailing slash; GitHub Pages adds it automatically.

Privacy policies for **Abduction Denied!** are available in English and German.

## Publishing

GitHub Pages serves the `main` branch from `/ (root)`. The site is plain HTML and
CSS; `.nojekyll` disables Jekyll processing. No build dependencies are required.
Both policies use a dark theme on screen and a light layout when printed.

Edit `privacypolicy/index.html` and `datenschutz/index.html` together so the
English and German versions stay consistent. Keep previous effective versions in Git history.

For privacy and data-deletion requests, email **kimkahns@googlemail.com**. Do not
post personal account data or authentication credentials in public issues.
