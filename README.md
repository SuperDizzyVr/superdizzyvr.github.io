# SuperDizzy VR website

Public GitHub Pages website for SuperDizzy VR.

- English privacy policy: https://superdizzyvr.github.io/
- German privacy policy: https://superdizzyvr.github.io/de/

The current **Abduction Denied!** privacy policy is a review draft. Its visible
draft notice stays in place until the described logging, retention and deletion
practices are implemented and verified. Do not submit the draft as the final Meta
privacy policy.

## Publishing

GitHub Pages serves the `main` branch from `/ (root)`. The site is plain HTML and
CSS; `.nojekyll` disables Jekyll processing. No build dependencies are required.

Edit `index.html` and `de/index.html` together so the English and German versions
stay consistent. Keep previous effective versions in Git history.

For privacy and data-deletion requests, email **kimkahns@googlemail.com**. Do not
post personal account data or authentication credentials in public issues.
